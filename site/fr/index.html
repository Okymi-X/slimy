Compagnon de bureau libre

UN SLIME QUI VIT SUR VOTRE ÉCRAN.

Slimy est un compagnon de gel translucide posé sur votre bureau. Il suit votre souris, retient ce que vous lui dites, parle avec une voix locale et demande avant de faire quoi que ce soit.

CE QU'IL FAIT

Un petit corps au-dessus de vos fenêtres, cinq habitudes.

  • Vit sur votre écran

    corps mou, physique

    Un corps mou simulé. Il roule le long des bords de fenêtre, s'écrase quand on le lâche, tend un bras vers votre curseur et s'endort quand rien ne se passe.

    • Corps mou
    • WebGL2

  • Se souvient et rappelle

    mémoire locale

    Dites-lui un fait ou une échéance. Il la garde dans un fichier local et vous la rend dans un court point du matin.

    • Fichier local
    • Point du matin

  • Parle et écoute en local

    voix sur la machine

    La reconnaissance vocale avec Whisper et la synthèse de voix tournent sur votre machine. Aucun son n'est envoyé à un serveur.

    • Whisper
    • Kokoro

  • Évolue pendant la nuit

    génome quotidien

    Chaque nuit, un génome de traits du corps et de la matière bouge un peu, selon ce que la journée a contenu. Les changements sont bornés et consignés.

    • Génome
    • Borné

  • Demande avant chaque action

    accord d'abord

    Voir l'écran, le presse-papiers, les fichiers, les outils, le pointeur et le micro sont refusés tant que vous ne les accordez pas.

    • Sur accord
    • Journalisé

VIE PRIVÉE ET CONTRÔLE

Chaque pouvoir démarre éteint.

Refusé par défaut
Chaque pouvoir démarre éteint. Rien ne tourne avant votre accord.
Limité dans le temps
Un accord dure 5, 15 ou 60 minutes. Vous pouvez le retirer à tout moment.
Journalisé
Ce qu'il a fait est écrit dans un journal que vous pouvez lire.
Clés dans votre trousseau
Les clés d'API vont dans le trousseau du système, jamais dans un fichier.

Ce qui quitte votre machine

Toujours
Le texte de la discussion, vers le fournisseur que vous avez choisi.
Avec accord
Une capture d'écran, vers le même fournisseur, quand vous lui demandez de regarder.
Jamais
L'audio de la voix et la base de souvenirs restent sur la machine. Avec Ollama, la discussion reste locale aussi.

INSTALLER

Linux d'abord. Il n'y a pas encore d'installeur : on compile depuis les sources. Des fichiers prêts à l'emploi viendront sur la page des versions.

1. Paquets système (noms Fedora)

sudo dnf install webkit2gtk4.1-devel libsoup3-devel librsvg2-devel \
  openssl-devel libappindicator-gtk3-devel libxdo-devel

Sur une autre distribution, installez les mêmes bibliothèques sous leurs noms. Il faut aussi une chaîne Rust.

2. Compiler et lancer

git clone https://github.com/Okymi-X/slimy.git
cd slimy
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli
./scripts/build-web.sh
cargo build -p slimy-desktop --features custom-protocol --release
target/release/slimy-desktop

  • Linux testé

    Compilé et lancé sur Fedora avec GNOME. Il passe par XWayland.

  • Windows non testé

    Le code propre à la plateforme existe mais n'a jamais été compilé ni lancé. Commencez par cargo check.

  • macOS non testé

    Même état que Windows. Retours et correctifs bienvenus.
