A slime that lives on your screen.

Slimy is a translucent gel pet on your desktop. It follows your mouse, remembers what you tell it, talks with a local voice, and asks before it does anything.

What it does

One small body on top of your windows, five habits.

  • Lives on your screen

    Soft body physics. It rolls along window edges, squashes when you drop it, reaches toward your cursor and falls asleep when nothing happens.

  • Remembers and reminds

    Tell it a fact or a deadline. It keeps it in a local database and gives it back in a short morning briefing.

  • Talks and listens locally

    Speech to text with Whisper and speech synthesis both run on your machine. No audio is sent to a server.

  • Evolves overnight

    Each night a genome of body and material traits shifts a little, based on what the day held. Changes are bounded and recorded.

  • Asks before every action

    Seeing the screen, the clipboard, files, tools, the pointer and the microphone are each refused until you grant them.

See it

Privacy and control

  • Refused by default. Every power starts off. Nothing runs until you say so.
  • Time limited. A grant lasts 5, 15 or 60 minutes. You can take it back at any moment.
  • Journaled. What it did is written to a journal you can read.
  • Keys stay in your keyring. API keys go to the system keyring, never to a file.

What leaves your machine

Always
The chat text you send, to the provider you chose.
With consent
One screenshot, to the same provider, when you ask it to look.
Never
Voice audio and the memory database stay on the machine. Pick Ollama and the chat stays local too.

Install

Linux first. There is no installer yet, so you build it from source. Prebuilt files will appear on the releases page.

1. System packages (Fedora names)

sudo dnf install webkit2gtk4.1-devel libsoup3-devel librsvg2-devel \
  openssl-devel libappindicator-gtk3-devel libxdo-devel

On other distributions, install the same libraries under their own names. You also need a Rust toolchain.

2. Build and run

git clone https://github.com/Okymi-X/slimy.git
cd slimy
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli
./scripts/build-web.sh
cargo build -p slimy-desktop --features custom-protocol --release
target/release/slimy-desktop

Linux tested

Built and run on Fedora with GNOME. It runs through XWayland there.

Windows untested

The platform code exists but has never been built or run. Start with cargo check.

macOS untested

Same state as Windows. Reports and fixes are welcome.

Open source

Slimy is released under the MIT licence. Read it, change it, ship your own.

The French voice is optional and lives behind the french-voice feature. It uses espeak-ng, which is GPL-3, so a build with that feature on is covered by the GPL. A default build is not.
